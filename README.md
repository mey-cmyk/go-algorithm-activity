# Go Dijkstra and Kruskal Activity

This repository contains my Go programming activity on graph algorithms, focusing on Dijkstra's Algorithm and Kruskal's Algorithm.

## Activities

- Dijkstra's Algorithm
- Kruskal's Algorithm
- minimum spanning tree(MST)

## Overview

### Dijkstra's Algorithm

Dijkstra's Algorithm is used to find the shortest path from a starting vertex to other vertices in a weighted graph with non-negative edge weights.

### Kruskal's Algorithm

Kruskal's Algorithm is used to find a Minimum Spanning Tree (MST) by selecting edges in increasing order of weight while avoiding cycles.

## Learning Goals

- Understand graph representation
- Implement Dijkstra's Algorithm in Go
- Implement Kruskal's Algorithm in Go
- Understand shortest paths and Minimum Spanning Trees
- Practice working with graphs and weighted edges
